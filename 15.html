ITEM 03 영상 기반 엘리베이터 오토패스 해결 시나리오 · 접근 방법 15 / 20

무게 대신 눈으로 본다

영상은 엣지 장비 안에서만 처리하고, 밖으로는 인원수와 포화도라는 숫자만 내보냅니다.

동작 시나리오

  1. 카 내부 카메라와 승강장 카메라 영상을 엣지 디바이스가 직접 수신
  2. 어안 왜곡을 보정한 뒤 머리 검출과 군중 밀도 추정으로 인원수와 점유 면적을 산출
  3. 도어 라인 통과를 추적해 승하차 인원을 카운팅하고, 포화도(0–1)를 실시간 보정
  4. 호출 버튼 · 현재 층 · 운행 방향과 결합해 바이패스 여부를 판단
  5. 영상은 엣지 밖으로 나가지 않고, 숫자만 관제 대시보드로 전송
  6. 실제 제어 대신 시뮬레이터에 정책을 적용해 대기시간 개선 효과를 측정

문제 → 해결 방법 대응

  • 무게 기준의 부정확성 → 실제 점유 면적을 호모그래피로 계산
  • 밀집 가림 → 머리 검출 + 밀도 추정 앙상블로 과소 추정 보완
  • 대기 수요 미파악 → 승강장 카메라로 층별 대기 인원 산출
  • 개인정보 → 온디바이스 처리, 원본 미저장·미전송
  • 실제 제어 불가 → 권고 출력 + 시뮬레이터로 효과 검증
