호스트 기기가 곧 서버다

인터넷 대신 호스트 기기가 직접 핫스팟과 웹서버를 띄우고, 참가자는 QR로 브라우저에 접속합니다.

사용 시나리오

  1. 호스트가 앱을 실행하면 기기에 로컬 웹서버와 Wi-Fi 핫스팟이 함께 기동된다
  2. 화면의 접속 QR을 참가자가 카메라로 찍어 브라우저로 입장 — 앱 설치 없음
  3. 호스트 기기를 테이블 중앙에 두고 퍼블릭 뷰(공용 보드 · 점수판)로 사용
  4. 자기 차례엔 기기를 집어 들고 제스처로 프라이빗 뷰(내 손패)로 전환
  5. 연결이 끊긴 참가자는 재접속 시 직전 상태로 자동 복구되어 게임이 끊기지 않는다

문제 → 해결 방법 대응

  • 인터넷 없음 → 호스트 내장 서버 + 핫스팟, 외부 통신 0
  • 참가자 설치 부담 → 설치 없는 PWA를 QR로 배포
  • 룰 설명 부담 → 단계별 가이드 UI가 가능한 행동만 노출
  • 화면 겸용 → 퍼블릭/프라이빗 듀얼 뷰 즉시 전환
  • 호스트 이탈 → 이벤트 소싱 + 스냅샷으로 상태 복구
