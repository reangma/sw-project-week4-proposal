ITEM 02 창작 설정 검증 어시스턴트 해결 시나리오 · 접근 방법 10 / 20

글을 쓰면 설정집이 따라 자란다

작가는 평소처럼 쓰기만 하고, 설정의 축적과 검증은 도구가 배경에서 수행합니다.

사용 시나리오

  1. 기존 원고와 설정집을 올리면 인물 · 장소 · 사건 · 규칙을 엔티티로 자동 추출
  2. 추출 결과는 지식그래프로 쌓고, 원문은 벡터 인덱스로 검색 가능하게 저장
  3. 집필 중 문단이 바뀔 때마다 변경분만 증분 분석해 비용과 지연을 최소화
  4. 기존 설정과 충돌하면 그 자리에 밑줄 경고 + 근거가 된 원문 위치를 함께 표시
  5. 플로팅 패널에는 캐릭터 상태·감정 타임라인과 자동 챕터 요약이 실시간 갱신
  6. 의도한 설정 변경이면 예외로 등록해 이후 같은 경고를 띄우지 않음

문제 → 해결 방법 대응

  • 기억 한계 → 지식그래프에 속성 타임라인으로 축적
  • 컨텍스트 한계 → RAG로 관련 근거만 선별해 모델에 투입
  • 오탐 불신 → 근거 원문 인용 의무화 + 신뢰도 등급 표시
  • 의도된 반전 → 권고 수준 경고와 예외 등록 학습
  • 비용·지연 → 증분 처리 + 결과 캐싱, 판정 단계만 큰 모델
